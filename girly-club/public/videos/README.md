# Vidéo d'ambiance de la page d'accueil

Déposez ici :

- `hero.mp4` : une courte vidéo du club (10 à 20 secondes, sans son, format paysage ou portrait, idéalement moins de 5 Mo)
- `hero-poster.jpg` : une image tirée de la vidéo (affichée pendant le chargement)

Tant que ces fichiers sont absents, un fond animé aux couleurs du club s'affiche à la place.
